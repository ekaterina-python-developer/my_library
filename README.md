# MyLibrary API - Домашняя библиотека

REST API для управления домашней библиотекой книг. 

## Особенности

- Полностью асинхронный - все операции выполняются асинхронно.

- Управление книгами - CRUD операции для книг.

- Валидация данных - строгая валидация с помощью Pydantic.

- Чистая архитектура - разделение на слои (модели, схемы, репозитории, роутеры).

- Автоматическая документация - интерактивная документация Swagger UI.

- SQLite база данных - легковесная база данных для хранения книг.

## Стек технологий
FastAPI
SQLAlchemy 
Pydantic 
SQLite 
Uvicorn 
aiosqlite 

## Установка и запуск
'''
1. Клонирование репозитория
git clone <ваш-репозиторий>

## API Endpoints
Книги (/books)
### 1. Получить все книги
Метод: GET /books
Описание: Возвращает список всех книг в библиотеке
Ответ: 200 OK - список объектов SBook
Пример ответа:

'''
[
  {
    "id": 1,
    "title": "Мастер и Маргарита",
    "author": "Михаил Булгаков",
    "year": 1967,
    "pages": 480,
    "is_read": true
  }
]
'''
### 2. Получить книгу по ID
Метод: GET /books/{id}
Описание: Возвращает книгу по указанному идентификатору
Параметры: id (int) - идентификатор книги
Ответ: 200 OK - объект SBook
Ошибки: 404 Not Found - если книга не найдена

### 3. Добавить новую книгу
Метод: POST /books
Описание: Добавляет новую книгу в библиотеку
Тело запроса: объект SBookAdd
Ответ: 201 Created - созданный объект SBook
Пример запроса:

'''
{
  "title": "Преступление и наказание",
  "author": "Фёдор Достоевский",
  "year": 1866,
  "pages": 592,
  "is_read": false
}
'''
### 4. Полное обновление книги (PUT)
Метод: PUT /books/{id}
Описание: Полностью обновляет все поля книги
Параметры: id (int) - идентификатор книги
Тело запроса: объект SBookAdd
Ответ: 200 OK - обновленный объект SBook
Ошибки: 404 Not Found - если книга не найдена

### 5. Удалить книгу
Метод: DELETE /books/{id}
Описание: Удаляет книгу из библиотеки
Параметры: id (int) - идентификатор книги
Ответ: 204 No Content - без тела ответа
Ошибки: 404 Not Found - если книга не найдена
